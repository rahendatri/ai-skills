# Explanation
## Input
A research request describing the sector, topic, or company landscape to investigate.
Optionally, the request can specify:
- the language(s) sources and the report should use
- the depth (quick briefing vs. exhaustive report)
- a time window for the data to cover
# Output
- A Markdown report with inline hyperlinked citations and a Sources list
- A standalone HTML report with the same citation structure
- A 5-slide HTML deck (companion artifact, keyboard-navigable)
## How it works
This skill conducts source-grounded market research in the following steps:
1. Scope the request (subject, language, depth, time window) and confirm understanding before researching
2. Gather sources, capturing each claim with its grounding excerpt and citation details as research proceeds
3. Write the report, attaching an inline hyperlinked citation to every non-obvious claim, closing with a deduplicated Sources list
4. Verify citation accuracy and cross-section consistency, then deliver in the requested format
